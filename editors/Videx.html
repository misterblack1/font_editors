Characters ($00-$7F)

128 characters, 16 bytes each, indexed by ASCII code. Height sets how many rows to show. Plain letters use 7-9, line-drawing glyphs can use all 14.

Most ROMs: sh0 w8. Bit 7 carries data on line-drawing chars, so sh1 w7 crops it silently (plain text still looks fine either way). Some chips are bitwise-inverted; use the Inverse preset for those.

Unused bits are left alone on save.
