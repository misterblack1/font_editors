Characters ($00-$FF)

IBM CGA and MDA character ROMs are always 8 pixels wide. MDA hardware duplicates the right most pixel to create the 9th pixel.

Mirror/Invert stay adjustable in case an unusual clone ROM packs its bits backwards or inverted.

Each block is 2KB and can be set to CGA (8x8, one block) or MDA (8x14, two blocks) using the dropdown next to it. Picking MDA pairs that block with the next one: rows 0-7 come from the first block, rows 8-13 come from the first 6 bytes of each character's slot in the second block. The leftover 2 bytes per character in that second block are unused.

Edits always preserve the bytes' unused bits exactly as loaded. Saving writes the file in the exact same byte layout it was loaded in, only the pixels you actually edit change.
